# Comprehensive SEO Optimization Brief — PrimeOMS

## Project Overview

You are an expert SEO strategist, technical SEO specialist, SaaS marketing consultant, and website growth engineer.

Your task is to perform a complete SEO audit and implement a comprehensive SEO strategy for **PrimeOMS**, an Order Management System developed by **Infectech Ltd.**

Website: https://primeoms.infec.tech/

Parent Company: https://infec.tech/

PrimeOMS is a business management platform designed to help e-commerce businesses streamline their operations, manage orders, inventory, products, customers, and business workflows from one centralized system.

The primary goal is to establish PrimeOMS as a recognizable and searchable SaaS product, attract qualified organic traffic, and generate potential customers through search engines.

## 1. Initial Website Audit

Before making changes, thoroughly inspect the entire website.

Analyze:

- Homepage structure and content.
- All existing pages and routes.
- Navigation and internal linking.
- Page titles and meta descriptions.
- Heading hierarchy (H1–H6).
- Existing keywords and keyword placement.
- Image optimization and alt attributes.
- URL structure.
- Mobile responsiveness.
- Page loading performance.
- Core Web Vitals.
- Technical SEO issues.
- Indexability and crawlability.
- Existing structured data.
- Content gaps and opportunities.

Do not blindly replace existing content. Preserve the product's actual functionality, brand positioning, and existing design identity.

## 5. Technical SEO

Implement and verify the following:

### Search Engine Indexing
- Generate a valid XML sitemap.
- Configure robots.txt properly.
- Set canonical URLs.
- Ensure important pages are indexable.
- Prevent duplicate URL indexing.
- Configure appropriate redirects.
- Avoid broken links and 404 errors.

### Metadata and Social Sharing
Implement:
- SEO title and meta description.
- Canonical tags.
- Open Graph title.
- Open Graph description.
- Open Graph image.
- Twitter/X card metadata.
- Appropriate favicon.

### Structured Data

Implement relevant JSON-LD structured data where appropriate:

- Organization
- SoftwareApplication
- WebSite
- BreadcrumbList
- FAQPage only where eligible and appropriate.

Use accurate information. Never invent ratings, reviews, prices, or product capabilities.

### Performance

Optimize:

- Image formats (WebP/AVIF).
- Image dimensions and lazy loading.
- JavaScript bundles.
- CSS delivery.
- Font loading.
- Caching.
- Server response time.
- Core Web Vitals.

Prioritize mobile performance.

## 6. Bangladesh and International SEO

Position PrimeOMS primarily for the Bangladesh e-commerce market while maintaining international search potential.
